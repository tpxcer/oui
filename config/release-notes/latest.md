## OUI 2026.10.14

- 首页顶部状态区改为主次分明的布局：左侧突出显示实时上传、下载速度和网速趋势图，右侧以仪表行集中展示 `CPU`、内存、交换分区和存储的占用率、容量、近期走势与进度条。
- 资源占用达到 80% 时仪表变为黄色，达到 90% 时变为红色；桌面端左右并排，较窄窗口自动上下排列，手机单栏显示。
- 趋势图只绘制真实采样，打开首页时不再用第一个采样补满开头，避免出现虚假的平台曲线。
- Go 工具链升级至 `1.26.9`，同步更新 `golang.org/x/net`、`golang.org/x/text`、`golang.org/x/crypto`、`gRPC` 等依赖，修复 HTTP/2、TLS、HTML 模板等多项安全公告。
- 更新前端构建依赖 `source-map-js`，清除依赖安全审计发现的高危公告。
