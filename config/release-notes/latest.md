- 移除未使用的 Swagger 文档组件和未接入的分组页面，前端依赖审计清零；同步更新 GitHub Actions、gopsutil、validator、Ant Design 图标、i18next、React Router、ESLint 等依赖；清理重复过时的多语言 README。
