## OUI 2026.8.30

- 服务器原有手动放行不会被删除；多个本机节点共用端口时保留规则，仅关闭节点时也不会关闭端口。

- 关闭订阅服务后，Telegram 一键创建不再生成或发送订阅相关内容，独立节点链接和二维码保持可用。
- 更新前端安全依赖，当前依赖审计为 0 漏洞。
- 升级 Go 构建版本和 gRPC 依赖，修复当前 Go 漏洞扫描检出的可达安全问题。
